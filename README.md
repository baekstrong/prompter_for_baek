# Prompter for Baek

아이폰 전면 카메라로 촬영하면서 대본을 읽는 개인용 프롬프터 웹앱.

## 현재 상태

기획 단계입니다. 요구사항과 구현 방향을 정리했으며, 실행 가능한 앱은 아직 구현하지 않았습니다. 개발은 사용자 컨펌 후 시작합니다.

## 목표

- CapCut에서 사용하던 촬영용 프롬프터 기능을 대체합니다.
- 별도 구독료나 Apple 개발자 멤버십 없이 운영하는 구성을 우선합니다.
- Safari에서 실행하고 홈 화면에 추가할 수 있는 웹앱(PWA)을 목표로 합니다.
- 촬영 영상은 서버에 업로드하지 않고 아이폰 안에서 처리합니다.

## 제안 기능

- 대본 붙여넣기·수정·로컬 저장, 문장 줄바꿈과 문단 간격 보존
- 렌즈 가까이 옮길 수 있는 대본창과 글자 크기·폭·배경 투명도 조절
- 일정 속도 자동 스크롤, 대본만 일시정지·재개, 앞부분으로 되돌리기
- 전면 카메라·마이크 녹화, 가로·세로 화면, 시작 카운트다운
- 대본이 포함되지 않은 영상 출력과 사용자 버튼을 통한 공유·다운로드

## 구현 방향과 검증

카메라·마이크 스트림은 `getUserMedia`로 가져오고 `MediaRecorder`로 녹화합니다. 대본은 미리보기 위의 별도 화면 요소로 표시합니다. 무료 정적 호스팅의 기본 주소를 사용하고, 영상 업로드 서버나 유료 API를 두지 않는 방향입니다.

첫 검증 목표는 1080p·30fps입니다. 실제 제공되는 해상도와 프레임률은 기기에서 확인하며, 4K 지원을 미리 보장하지 않습니다.

사용자의 아이폰 모델·iOS 버전·평소 연속 촬영 길이를 확인한 후 녹화, 저장, 재생과 음성 싱크를 먼저 검증합니다. 화면 잠금이나 다른 앱으로 전환한 상태에서의 연속 녹화는 보장하지 않습니다. 사진 앱 자동 저장 대신 지원 여부에 따라 공유 시트 또는 파일 다운로드를 제공합니다.

무료 운영은 선택한 호스팅의 현행 무료 플랜 범위에 따릅니다. 배포 서비스와 실제 촬영 환경은 아직 확정하지 않았습니다.

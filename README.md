# Prompter for Baek · 프롬프터

아이폰 전면 카메라로 촬영하면서 대본을 읽는 개인용 웹앱입니다. 별도 유료 API나 서버 없이 대본과 영상을 브라우저 안에서 처리합니다.

## 실행

- 사용 주소: https://prompter-for-baek.rich-mango-0430.chatgpt.site (소유자 전용 Sites 배포)
- 아이폰 Safari로 열고 카메라·마이크 접근을 허용합니다.
- Safari 공유 메뉴 → **홈 화면에 추가**로 설치할 수 있습니다.
- 대본을 붙여 넣고 **읽기 연습**으로 속도를 맞춘 뒤 **녹화 시작**을 누릅니다.
- 종료 후 **공유 / 사진에 저장**에서 기기가 제공하는 저장 메뉴를 선택하거나 **파일로 저장**을 누릅니다. 사진 앱 자동 저장은 하지 않습니다.

## 구현 기능

- 대본 편집·TXT 불러오기·자동 저장, 문장 줄바꿈과 문단 간격 보존
- 드래그 및 방향키로 대본 위치 이동, 글자 크기·폭·배경 농도·속도 조절
- 자동 스크롤·대본만 일시정지/재개·처음으로, 키보드 Space 재생/일시정지
- 전면/후면 카메라·마이크 녹화, 0/3/5초 카운트다운
- 촬영 화면 확대, 가로/세로 레이아웃, 미리보기 좌우 반전
- 대본이 포함되지 않는 원본 영상, MP4 우선 지원 여부 확인 후 WebM 대체
- 기기 보관함·재생·공유·다운로드·개별 삭제
- 1초 간격 녹화 청크 저장 및 중단된 촬영의 저장 구간 조회
- 화면 꺼짐 방지 요청, 카메라 끄기, 앱 전환·입력 중단 시 녹화 종료
- 오프라인 앱 셸. 업데이트로 촬영 중인 페이지를 강제 재시작하지 않습니다.

## 30분~1시간 촬영 기준과 확인 사항

사용자의 일반적인 촬영 길이는 **보통 30분, 1시간 이내**입니다. 영상 4Mbps·음성 128kbps를 요청하므로 30분은 대략 0.93GB, 1시간은 1.86GB 수준이지만 실제 용량·화질은 브라우저와 기기에 따라 다릅니다. 녹화 시간을 임의로 제한하지 않으며 해당 길이의 실기기 검증은 아직 하지 않았습니다.

- 해상도 1920×1080, 30fps를 ideal로 요청하고 실제 카메라 설정을 설정창에 표시합니다. 기기가 더 낮은 설정을 반환할 수 있습니다.
- 녹화 중 청크는 IndexedDB에 순서대로 보관하고, 저장이 끝난 청크는 메모리 큐에서 제거합니다. 저장 오류나 미저장 청크 64MiB 도달 시 자동 종료하여 회수 가능한 영상을 제공합니다. 브라우저가 마지막에 생성하는 청크의 크기까지 앱이 제한할 수는 없습니다.
- 화면의 여유 용량은 **브라우저 저장 할당량 추정치**이며 기기 물리 저장 공간과 다를 수 있습니다. 보관함 영상은 필요한 만큼 파일로 내보낸 뒤 사용자가 삭제해야 합니다.
- 페이지가 강제 종료되면 이미 저장된 청크만 남습니다. 중단된 파일의 재생 가능성과 마지막 구간 보존은 녹화 형식·종료 시점에 따라 달라집니다. 완전한 복구를 보장하지 않습니다.
- 화면 잠금·앱 전환·전화 등으로 입력이 중단되면 촬영을 종료합니다. 촬영 중 방향을 바꾸지 마세요. 전면 미리보기만 좌우 반전하고 녹화 파일에는 적용하지 않습니다.
- iPhone 모델·iOS 버전은 아직 확인하지 않았습니다. 실제 아이폰에서 ① 10초 영상의 방향·음성·저장 ② 30분 연속 촬영·싱크·발열 ③ 평소 최대 길이 촬영 순서로 확인이 필요합니다.
- iOS Safari 세로 녹화에는 [기기별 방향 문제 보고](https://bugs.webkit.org/show_bug.cgi?id=323550)가 있습니다. 세로 촬영 파일의 방향은 실기기에서 확인해야 합니다.

대본은 localStorage, 촬영 영상은 IndexedDB에 보관합니다. 브라우저 데이터 삭제·비공개 모드·OS의 저장 공간 회수로 자료가 없어질 수 있으므로 필요한 영상은 파일/사진 앱에 저장해 주세요. 앱이 대본이나 영상을 서버로 업로드하지는 않습니다.

## 로컬 개발

Node.js 20 이상. 런타임 의존성이 없고 설치/빌드 없이 실행됩니다.

```sh
npm run dev
# http://127.0.0.1:4173
npm run check
npm test
```

HOST·PORT 환경변수로 수신 주소를 바꿀 수 있습니다. 아이폰에서 LAN의 일반 HTTP 주소로 접속하면 카메라를 사용할 수 없으므로 HTTPS 배포 주소를 이용합니다. dist/ 전체를 정적 호스팅에 올리면 됩니다. 프로젝트는 기존 GitHub 저장소 baekstrong/prompterforbaek을 유지하며 Sites 소유자 전용 주소로 배포합니다. 유료 API나 결제를 추가하지 않았으며 서비스의 향후 요금 정책은 별도입니다.

## 검증

- npm test: 카메라 상태/권한·취소 경합·최종 청크·IndexedDB·저장 오류·입력 중단, 대본 설정/스크롤, 서버/PWA 테스트.
- 선택 브라우저 통합 검사: Playwright를 별도로 준비하고 서버 실행 후 node scripts/browser-test.mjs를 실행합니다. 외부 Playwright 모듈과 브라우저는 PROMPTER_PLAYWRIGHT_MODULE, PROMPTER_BROWSER_PATH로 지정할 수 있습니다.
- Chromium 가상 카메라·음성으로 대본 보존, 스크롤, 준비 취소, 1080p 녹화·재생·다운로드, 재접속 복구, 오프라인 실행, 393px 세로/852px 가로 레이아웃을 확인했습니다. 이는 실제 아이폰이나 30분~1시간 촬영 검증을 대신하지 않습니다.
- 로컬 스크린샷과 테스트 영상은 .artifacts/에 생성하고 Git 및 배포 소스에서 제외합니다.

## 파일 구성

- dist/app.js: 화면과 대본 조작
- dist/core.js: 설정과 스크롤 계산
- dist/camera.js: 카메라와 녹화 상태
- dist/recording-store.js: 기기 저장
- dist/sw.js: 앱 셸만 캐시. 녹화 영상은 캐시하지 않음
